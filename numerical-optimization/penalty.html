7  Penalty Methods

Constrained optimization problem: \[ \min_{x\in\mathbb{R}^n} f(x), \quad \text{s.t.}\quad \begin{cases} G_i(x)=0, & i\in\mathcal{E} \\ G_i(x)\geq 0, & i\in\mathcal{I} \end{cases} \]

We need to minimize the problem as well as achieving feasibility.

Motivation: construct an auxiliary objective function s.t. the deviation from feasibility is penalized.

7.1 Quadratic Penalty Function

Equality constrained case

\[ \min_{x\in\mathbb{R}^n} f(x), \quad \text{s.t.}\quad G_i(x)=0,\ i\in\mathcal{E}. \]

penalty function \[ Q(x,\mu) := f(x) + \frac{\mu}{2}\sum_{i\in\mathcal{E}} G_i^2(x), \qquad \mu>0 \text{ is the penalty parameter.} \]

larger \(\mu\) \(\to\) more penalty on \(G_i(x)\) \(\to\) close to the exact constraint.

Sequential consideration. consider a sequence \(\{\mu_k\}\to\infty\), and the quadratic problem \(\min_{x\in\mathbb{R}^n} Q(x,\mu_k)\) for each \(k\), with optimizer \(x_k\).

Comparing the original problem with the penalty problem: \[ \underbrace{\min f(x),\ G_i(x)=0}_{\displaystyle \nabla f(x) - \sum_i \lambda_i\nabla G_i(x)=0} \qquad\qquad \underbrace{\min f(x) + \tfrac{\mu}{2}\textstyle\sum_i G_i^2(x)}_{\displaystyle \nabla f(x) + \mu\sum_i G_i(x)\nabla G_i(x)=0} \] For the penalty problem, \(\mu\to\infty\), \(G_i(x)\to 0\) to keep a finite value. We would hope that when \(\mu_k\to\infty\), \(x_k=\arg\min Q(x,\mu_k)\to x^\ast\).

Theorem 7.1 (Convergence condition) suppose the original problem has a global minimizer. Let \(x_k\) be the global minimizer of \(Q(x,\mu_k)\), and \(\mu_k\to\infty\). Then every limit point \(x^\ast\) of \(x_k\) is a global solution of the original problem.

Convergence property

Let \(x_k\) be generated by the quadratic penalty method with \(\tau_k\to 0\) and \(\mu_k\to\infty\). Let \(x^\ast\) be a limit point of the sequence \(\{x_k\}\).

  • if \(x^\ast\notin\Omega\), then it is a stationary point of \(\lVert C(x)\rVert^2\).
  • if \(x^\ast\in\Omega\), and LICQ hold at \(x^\ast\), then \(x^\ast\) is a KKT point with \(\lambda^\ast\), and satisfy \[ \lim_{k\in K} -\mu_k G_i(x_k) = \lambda_i^\ast,\ \forall i\in\mathcal{E} \quad\text{and infinite subsequence } \lim_{k\to K} x_k = x^\ast. \]

Remarks:

  • The quadratic penalty may not converge to a feasible point.
  • If converge to a feasible point, \(\lim_{k\to\infty} -\mu_k G_i(x_k) = \lambda_i^\ast\) reduce to the KKT condition (\(\mu_k\to\infty\), \(G_i(x_k)\to 0\)).

Issues: ill-conditioned Hessian

\[ \nabla^2 Q = \nabla^2 f + \sum_i \mu_k G_i(x)\nabla^2 G_i(x) + \mu_k\sum_i \nabla G_i\nabla G_i^{\mathsf T} \] if converge to feasible: \[ \nabla^2 Q = \underbrace{\nabla^2 f - \sum_i \lambda_i^\ast\nabla^2 G_i(x)}_{\nabla^2\mathcal{L}} + \underbrace{\mu_k\sum_i \nabla G_i\nabla G_i^{\mathsf T}}_{\text{ill condition when }\mu\to\infty} \] Newton’s method might struggle.

Inequality constrained case

\[ \min_{x\in\mathbb{R}^n} f(x), \quad \text{s.t.}\quad G_i(x)=0,\ i\in\mathcal{E};\quad G_i(x)\geq 0,\ i\in\mathcal{I}. \] \[ \Rightarrow Q(x,\mu) = f(x) + \frac{\mu}{2}\sum_{i\in\mathcal{E}} G_i^2(x) + \frac{\mu}{2}\sum_{i\in\mathcal{I}} \big(\max\{0,\,-G_i(x)\}\big)^2 \] which is \(C^1\) only.

7.2 Augmented Lagrangian Method

In the quadratic penalty method, we wish \(-\mu_k G_i(x)\to\lambda_i^\ast \iff G_i(x) = -\dfrac{\lambda_i^\ast}{\mu_k}\), so \(\mu_k\to\infty\) to make sure \(G_i(x)=0\). However, \(\mu_k\) won’t need to go unbounded if we can make the numerator \(\to 0\).

Equality constrained case

\[ \min_{x\in\mathbb{R}^n} f(x), \quad \text{s.t.}\quad G_i(x)=0,\ i\in\mathcal{E} \;\Rightarrow\; \mathcal{L}_A(x,\lambda;\mu) = f(x) - \sum_{i\in\mathcal{E}}\lambda_i G_i(x) + \frac{\mu}{2}\sum_{i\in\mathcal{E}} G_i^2(x) \]

The KKT of the original problem is \(\nabla f - \sum_i \lambda_i\nabla G_i = 0\), \(G_i(x)=0\).

consider a sequence \(\lambda_k, \mu_k\): \[ \nabla\mathcal{L}_A = \nabla f - \sum_i \lambda_i^k\nabla G_i(x) + \mu_k\sum_i G_i\nabla G_i = \nabla f - \sum_i \big(\lambda_i^k - \mu_k G_i(x)\big)\nabla G_i(x_k). \] wish \(\lambda_i^k - \mu_k G_i(x)\to\lambda_i^\ast\) and \(x_k\to x^\ast\).

now \[ G_i(x) = \frac{\lambda_i^k - \lambda_i^\ast}{\mu_k} \to 0 \quad\text{if } \lambda_i^k\to\lambda_i^\ast. \]
