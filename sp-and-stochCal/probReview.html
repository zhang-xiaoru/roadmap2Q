16  Probability in Measure Theory Language

Sample space \(\Omega\): the set of all possible outcome of an experiment.

Event: a subsets of the sample space \(\Omega\).

  • \(\varnothing\) is impossible event
  • \(\Omega\) is certain event.

Bertrand’s Paradox: probability of chord intersect with inner circle.

An example of different

Remark: Events are subsets of \(\Omega\), but subsets of \(\Omega\) may not be an Event

we can therefor select subsets of \(\Omega\), which are events and form a collection \(\mathcal{F}\) (i.e., \(\mathcal{F} \subseteq 2^\Omega \leftarrow\) set of all subset of \(\Omega\)) and should have following property

    1. if \(A, B \in \mathcal{F}\) then \(A \cup B \in \mathcal{F}\) and \(A \cap B \in \mathcal{F}\)
    1. if \(A \in \mathcal{F}\) then \(A^c \in \mathcal{F}\).
    1. \(\varnothing \in \mathcal{F}\)

\(\mathcal{F} \subseteq 2^\Omega\) satisfied above is called a field.

Remark:

    1. \(\to \bigcup_i A_i \in \mathcal{F}\), \(\bigcap_i A_i \in \mathcal{F} \to\) close under finite union or intersect.
    1. This properties can be shown via easy coin toss or dice experiment

Infinite union and \(\cap\)’s: Consider an experiment. A coin is repeatedly tossed until the first head show up, try to find number of toss before this happen

\[ \Omega = \{\omega_1, \omega_2, \dots\}, \qquad \omega_i := \text{first } i{-}1 \text{ are tail}, \ i \text{ are head} \]

Event \(A :=\) the first head arrive after even number of tosses.

\[ A := \{\omega_2, \omega_4, \omega_6 \dots\} = \bigcup_{i=2} \omega_i \]

\(A\) should also in the event space \(\mathcal{F}\) \(\to\) \(\mathcal{F}\) should closed under infinite \(\bigcup_i \ \bigcap_i\)

16.1 \(\sigma\)-algebra / \(\sigma\)-field \(\to\) set of Events.

collection of subset of sample space \(\mathcal{F} \subseteq 2^\Omega\), is called a \(\sigma\)-algebra / \(\sigma\)-field if it satisfied following

  1. \(\varnothing \in \mathcal{F}\)
  2. if \(A \in \mathcal{F}\), \(A^c \in \mathcal{F}\) \(\ (A^c := \Omega - A) \to \Omega \in \mathcal{F}\)
  3. if \(A_1, A_2 \cdots \in \mathcal{F}\), then \(\bigcup_i^\infty A_i \in \mathcal{F}\), \(\bigcap_i^\infty A_i \in \mathcal{F}\)

16.2 Probability measure

suppose we have sample space \(\Omega\), and \(\sigma\)-algebra \(\mathcal{F}\). A probability measure is a function \(P : \mathcal{F} \to [0, 1]\) satisfying.

  1. \(P(\varnothing) = 0\), \(P(\Omega) = 1\)
  2. if \(A_1, A_2, \cdots \in \mathcal{F}\) and are disjoint \((A_i \cap A_j = \varnothing, \text{ for } \forall\, i \neq j)\) then

\[ P\!\left(\bigcup_i^\infty A_i\right) = \sum_{i=1}^{k} P(A_i) \]

The \((\Omega, \mathcal{F}, P)\) is called a probability space.

lemma:

    1. \(P(A^c) = 1 - P(A)\)
    1. if \(A \subseteq B\), \(P(A) \leq P(B)\)
    1. \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)
    1. \(P\!\left(\bigcup_{i=1}^n A_i\right) = \sum P(A_i) - \sum_{i<j} P(A_i \cap A_j) + \cdots (-1)^{n+1} P(A_1 \cap A_2 \cdots A_n)\)

16.3 Generated \(\sigma\)-field \(\to\) for uncountable \(\Omega\).

suppose a collection of subset \(A_\alpha \subseteq \Omega\), where \(\alpha \in T\) not necessarily countable. The smallest \(\sigma\)-field \(\mathcal{F}\) s.t. \(A_\alpha \in \mathcal{F}\), for \(\forall\, \alpha \in T\) is denoted as \(\sigma(\{A_\alpha\})\).

Then \(A_\alpha\) is called generator, and \(\sigma(\{A_\alpha\})\) is called \(\sigma\)-field generated by \(\{A_\alpha\}\)

\[ \sigma\{A_\alpha\} = \bigcap \left\{\, \mathcal{G} : \mathcal{G} \subseteq 2^\Omega \text{ is a } \sigma\text{-field}, \ A_\alpha \in \mathcal{G}, \ \forall\, \alpha \in T \,\right\} \]

Remark: if \(A_\alpha\) is \(\sigma\)-field for each \(\alpha \in T\). \(\bigcap_{\alpha \in T} A_\alpha\) is a \(\sigma\)

16.4 Borel \(\sigma\)-field on \(\mathbb{R}\).

a Borel \(\sigma\)-field on \(\mathbb{R}\) is a \(\sigma\)-field generated by \(\{(a,b), \ a<b \in \mathbb{R}\}\)

\[ \mathcal{B} = \sigma\big(\{(a,b), \ a<b \in \mathbb{R}\}\big) \iff \sigma\big(\{O \subseteq \mathbb{R} \text{ open}\}\big) \iff \sigma\big(\{(-\infty, b], \ b \in \mathbb{R}\}\big) \]

16.5 Random Variable (R.V.)

A R.V. is a function \(X : \Omega \to \mathbb{R}\) s.t. \(\forall\, \alpha \in \mathbb{R}\) the set \(\{\omega : X(\omega) \leq \alpha\}\) is in \(\mathcal{F}\) ( such function is also called \(\mathcal{F}\)-measurable ) (or just measurable)

equivently, the measurable means \(X\) is measurable. in \(\mathcal{F}\) if for \(\forall\, B \in \mathcal{B}(\mathbb{R})\), \(X^{-1}(B) \in \mathcal{F}\)

Remark: The R.V. create a mapping between outcomes and real numbers, in a way s.t. out comes that captures by any borel set (could be record as an event of random real space) is forming an events in event space of \(\Omega\).

16.6 \(\sigma\)-field generated by random variable.

suppose \(X\) is a R.V. on \((\Omega, \mathcal{F})\) the \(\sigma\)-field generated by \(X\), \(\sigma(X)\) si the smallest \(\sigma\)-field \(\mathcal{G} \subseteq \mathcal{F}\), s.t. \(X\) is still measurable on \((\Omega, \mathcal{G})\).

Remark: \(\{X^{-1}(B) \mid B \in \mathcal{B}\}\) is such smallest \(\sigma\)-algebra. (by definition, \(X\) is such function \(\Omega \to \mathbb{R}\), s.t. every \(B \in \mathcal{B}(\mathbb{R})\) is inside \(\mathcal{F}\), the smallest set from \(X\) is \(\{X^{-1}(B) \mid B \in \mathcal{B}\}\), only need to show \(\{X^{-1}(B) \mid B \in \mathcal{B}\}\) is \(\sigma\)-field)

Remark: The mapping of R.V. is chosen s.t. \(\omega \in \Omega\) enclosed by any \(B \in \mathcal{B}\) is belong to \(\sigma\)-field \(\mathcal{F}\). Thus \(\mathcal{F}\) contains all the information relavent to \(X\). the \(\sigma(X)\) is thus the least amout of information relevant to \(X\).

16.7 Simple function :

\[ X := \sum_{n=n}^{N} C_n \mathbf{1}_{A_n} \quad \text{is a R.V. for finite } N \text{ and } C_n \in \mathbb{R} \]

here \(A_n \in \mathcal{F}\) for any \(n\) and \[ \mathbf{1}_{A_n} := \begin{cases} 1, & \omega \in A_n \\ 0, & \omega \notin A_n. \end{cases} \]

prop: for every R.V. \(X\), there exist a sequence of simple functions \(X_n\) s.t. \(X_n(\omega) \to X(\omega)\) as \(n \to \infty\) for \(\forall\, \omega \in \Omega\).

Remark: The R.V. \(X(\omega)\) is usually denote simple as \(X\) and sometime \(P(X^{-1}(B))\) as \(P(X \in B)\)

16.8 Two R.V. same (almost surely)

suppose \(X\) and \(Y\) are R.V. defined on \((\Omega, \mathcal{F}, P)\), we says \(X\) and \(Y\) are almost surely (a.s.) the same if \(P(\omega : X(\omega) \neq Y(\omega)) = 0\).

Remark: in many case, \(X \overset{a.s.}{=} Y\) is simply denote as \(X = Y\).

  • The a.s. notation applies to many other cases such as \(X \geq 0\) a.s. means \(P(\{\omega : X(\omega) < 0\}) = 0\).

16.9 Borel (measurable) function

A R.V. \(g\) defined on \((\mathbb{R}, \mathcal{B})\) is called a Borel function.

16.10 Extend Borel-\(\sigma\)-algebra to \(\mathbb{R}^n\).

A Borel-\(\sigma\)-field in \(\mathbb{R}^n\) is simply \[ \mathcal{B}_n = \sigma\big( [a_1, b_1] \times [a_2, b_2] \times \cdots \times [a_n, b_n]; \ a_i, b_i \in \mathbb{R}, \ i = 1, \dots, n \big) \]

16.11 Expected Value.

Integration w.r.t. measure , lebesgue integral

  1. Simple R.V. Def

    suppose \(X\) on \((\Omega, \mathcal{F}, P)\) is Simple value R.V. \(X = \sum_{i=1}^{k} C_i \mathbf{1}_{A_i}\), then define \[ \int_\Omega X \, dP := \sum_{i=1}^{k} C_i P(A_i) \]

  2. if \(X\) is non negative R.V. \[ \int_\Omega X \, dP := \sup_{Y \leq X, \, Y \text{ simple}} \int_\Omega Y \, dP. \]

  3. if \(X : \Omega \to \mathbb{R}\), then \[ \int_\Omega X \, dP = \int_\Omega X^+ \, dP - \int_\Omega X^- \, dP. \qquad X^+ := \max(X, 0), \ X^- := \max(-X, 0) \]

Remark:

  • The integration is based on spliting the range of \(X(\omega)\) to small equal interval and approximating \(X(\omega)\) by a constant on the correspondy set of \(\omega\). values s.t. \(X(\omega)\) fall into the interval.
  • Contrast to Rieman where the domain of integration is split into intervals, limited to \(\mathbb{R}^n\).
  • lebesgue integral allows to deal with general domains.
  • If the correspondy Riemann integral exist, then it coincide with lebesgue integral.

16.12 Conditional probability

let \((\Omega, \mathcal{F}, P)\) be a prob space and. \(A, B \in \mathcal{F}\) and \(P(B) > 0\).

The conditional probability of \(A\), given \(B\) is \[ P(A \mid B) := \frac{P(A \cap B)}{P(B)} \]

motivation

want to find probability of \(A\), given \(B\), so suppose \(\omega \in \Omega\) and we know \(\omega \in B\), sure that, \(B\) can be considered as a new probability space, \((\Omega', \mathcal{F}', \hat{P})\), where \(\Omega' = B\), \(\mathcal{F}' := \{C \cap B \mid C \in \mathcal{F}\}\) and \(\hat{P} := \frac{P}{P(B)}\) so that \(\hat{P}(B) = 1\) then the probability \(\omega\) lies in \(A\) also is \(\hat{P}(A \cap B) = \frac{P(A \cap B)}{P(B)}\)

16.13 Independence

This means \(P(A \mid B) = P(A)\) (know \(B\) don’t give \(A\)). \[ \Rightarrow P(A \cap B) = P(A) P(B) \]

16.14 independent Random Variable

let \(X_i : \Omega \to \mathbb{R}^n\) be random variables \((i = 1, \dots)\). They are independent if for all \(k \geq 2\), \(k \in \mathbb{Z}\) and all choice of Borel set \(B_1, \cdots B_k \subseteq \mathbb{R}^n\). \[ P(X_1 \in B_1, X_2 \in B_2, \cdots X_k \in B_k) = P(X_1 \in B_1) P(X_2 \in B_2) \cdots P(X_k \in B_k). \] this essentrally means \(\sigma\)-field generated by each \(X_i\) \[ \sigma(X_i) \]

16.15 Conditional Expectation

\(E(X \mid B)\) the expected value of R.V. \(X\), given the event \(B\) happens.

From previous, we can think \(B\) form a new probability space, with \(\hat{P} = \frac{P}{P(B)}\) \(\Rightarrow E(X \mid B) = \frac{1}{P(B)} \int_B X \, dP\).

\(E(X \mid Y)\), the expected value of R.V., given another R.V. \(Y\) known.

consider the case with in \((\Omega, \mathcal{F}, P)\) where \(Y, X\) is defined \(Y = \sum_{i=1}^{m} c_i \mathbf{1}_{A_i}\), suppose \(c_i\) are distinct and \(A_1, A_2 \cdots A_m\) are disjoint.

\[ Y(\omega) = \begin{cases} c_1, & \omega \in A_1 \\ c_2, & \omega \in A_2 \\ \ \vdots \\ c_n, & \omega \in A_n \end{cases} \qquad \text{now if we know } Y(\omega) \to \text{ which event } A_i \]

\[ \text{thus } E(X \mid Y) = \begin{cases} \dfrac{1}{P(A_1)} \displaystyle\int_{A_1} X \, dP, & A_1 \\ \ \vdots \\ \dfrac{1}{P(A_n)} \displaystyle\int_{A_n} X \, dP, & A_n \end{cases} \]

  • \(E(X \mid Y)\) is R.V.
  • \(E(X \mid Y)\) is \(\sigma(Y)\) measurable
  • \(\int_A E(X \mid Y) \, dP = \int_A X \, dP \qquad \forall\, A \in \sigma(Y)\)

Def: let \(X, Y\) be R.V. defined on \(\Omega\), the conditional expectation of \(X\) given \(Y\) (\(E(X \mid Y)\)) is a \(\sigma(Y)\) measurable random variable \(Z\) s.t. \[ \int_A X \, dP = \int_A Z \, dP \qquad \text{for } \forall\, A \in \sigma(Y) \]

Remark: Such \(Z\) is unique up to set of probability zero. thus \(Z\) can just be denote as \(E(X \mid Y)\)

Def: \((\Omega, \mathcal{F}, P)\) be a probability space and \(\mathcal{V}\) is a \(\sigma\)-field, \(\mathcal{V} \subseteq \mathcal{F}\), if \(X : \Omega \to \mathbb{R}^n\) is an random variable, then \(E(X \mid \mathcal{V}) :=\) any R.V. on \(\Omega\) s.t.

  1. \(E(X \mid \mathcal{V})\) is \(\mathcal{V}\)-measurable.

  2. \(\int_A X \, dP = \int_A E(X \mid \mathcal{V}) \, dP\), for \(\forall\, A \in \mathcal{V}\)

Remark: \(E(X \mid \mathcal{V})\) can be understand as given the (information) available in a \(\sigma\)-field \(\mathcal{V}\), from which we intend to build an estimate of R.V. \(X\)

  1. \(\to E(X \mid \mathcal{V})\) has to be constructed from information in \(\mathcal{V}\).

  2. \(\to\) The estimation should be consist with \(X\), at least as regards in integration.

Th: let \(X\) be an integrable R.V. Then for each \(\sigma\)-field \(\mathcal{V} \subseteq \mathcal{F}\), the \(E(X \mid \mathcal{V})\) exists and is unique up to \(\mathcal{V}\)-measurable set of probability zero.
